# 🎉 Event Management System

A modern and responsive **Event Management System** designed to provide users with an easy way to explore and manage events through a clean and user-friendly web interface.

## 🚀 Live Demo

🔗 **Live Website:** https://event-management-system-yugen5.vercel.app/

## 📌 Project Overview

The **Event Management System** is a web-based application developed to simplify event discovery and management. The application provides an interactive interface where users can view event-related information and interact with the system through a responsive and intuitive design.

The project focuses on creating a simple, clean, and responsive frontend experience using standard web technologies.

## ✨ Features

* 🎉 Event management interface
* 📅 Event information and details
* 🖥️ Responsive user interface
* 📱 Mobile-friendly design
* 🎨 Clean and modern UI
* ⚡ Interactive JavaScript functionality
* 🧭 Easy navigation
* 🌐 Deployed and accessible online

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Application logic and interactivity
* **Vercel** – Deployment and hosting

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AnkanGhosh2026/Event_management_system.git
```

### 2. Navigate to the Project

```bash
cd Event_management_system
```

### 3. Run the Project

Since this is a frontend project, you can simply open:

```text
index.html
```

in your browser.

Alternatively, you can use **VS Code Live Server** for a better development experience.

## 💻 Running with VS Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The application will open in your default browser.
